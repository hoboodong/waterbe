# 워터비 사업 기준 (Canon)

이 문서는 사용자와 합의하며 쌓는 **워터비 사업의 공식 기준**이다.
메모리나 대화만으로 두지 않고, 여기서 확정한다.

최종 갱신: 2026-09-21

---

## 1. 공식 매장

시코드 앱에 등록된 매장 중 공식 매장은 다음 네 곳이다.

| store_id | 이름 |
|----------|------|
| `wangsimni` | 왕십리 |
| `mapo` | 마포 |
| `wolgye` | 월계 |
| `mia` | 미아 |

- `test`(테스트)는 공식 매장이 아니다.
- 시코드 기본 선택값은 `wangsimni`이다.

---

## 2. 공식 데이터 기준

**시코드 앱과 동기화되는 데이터가 공식 기준이다.**

- 현장·운영·상품·원재료 판단은 이 기준을 따른다.
- 중앙(워터비 YAML, Supabase 카탈로그 등)은 취합·배포·지원 역할이며, 앱 동기화 데이터와 어긋나면 앱 동기화 쪽을 공식으로 본다.

---

## 3. 상품

- 상품은 매장별(`store_id`)로 관리된다.
- 시코드 앱에 동기화된 상품 목록·내용이 현장 공식 기준이다.
- 문서상 구조(참고): 중앙 카탈로그(워터비 YAML → Supabase)가 기본 소스일 수 있고, 매장 등록·수정이 가능하며, `unlocked`이면 매장 독립 관리(자동 동기화 제외). 중앙과 다른 내용은 피드로 맞춘다.
- 그래도 **공식은 앱 동기화분**이다.

---

## 4. 원재료

원재료도 상품과 같은 기준(앱 동기화 = 공식)을 쓴다.

| 구분 | 역할 |
|------|------|
| `ingredients` | 재료 마스터 (이름, 원산지, 성분, 알레르기 등). 여러 상품·매장에서 재사용 |
| `product_ingredients` | 상품별 구성 (함량 %, 표시 순서 등). 상품에 딸린 상세 |
| 성분표 텍스트 | 상품/품질 쪽 `ingredients` 필드 등 라벨용 전체 텍스트 |

---

## 5. 정리 방식

워터비 사업 내용은 한 번에 다 쓰지 않고, **사용자와 하나씩 합의한 뒤 이 문서에 추가**한다.

다음에 잡을 항목은 대화에서 이어간다.
