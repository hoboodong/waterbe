# 품질관리솔루션 운영 지침

이 문서는 이마트 매장의 품질검사와 다이버시 위생점검에 앞서 시코드 상품, CL-5200 저울 PLU, 대표품질, 상품라벨과 원재료 원라벨을 순차적으로 대조하는 표준 절차다.

## 목적과 실행 요청

- 점검 목적은 식품 표시와 원재료 정보의 불일치, 누락, 기한 및 보관 문제를 점검 전에 찾아 수정 필요사항으로 보고하는 것이다.
- 사용자가 `품질관리솔루션 시작`, `품질검사 시작` 또는 `다이버시점검 시작`이라고 요청하면 이 문서의 순서로 점검을 시작한다.
- 시작할 때 대상 매장을 확인한다. 점검 대상은 해당 매장의 현재 시코드 운영상품이다.
- 이 절차는 조회와 대조 절차다. 불일치를 발견해도 사용자의 별도 요청 없이 시코드, 저울, 대표품질 또는 업무자료를 수정하지 않는다.
- 앱과 저울의 현재 상태는 실제 조회로 확인한다. 캐시나 오래된 자료만으로 적합 판정을 내리지 않는다.

## 필요한 자료

### 승인된 에이전트 상품 수정 — 앱과 같은 규칙 (2026-10-07)

- 사용자 합의: 에이전트가 수정하는 방식과 사용자가 시코드 앱에서 수정하는 방식은
  같은 검증·원재료 연결·저장·동기화·저울 연동 규칙을 따라야 한다.
  휴대폰 화면을 직접 조작해야 한다는 뜻은 아니다.
- 수정 승인을 받으면 시코드의 실제 상품 저장 계약을 확인한다. 공통 처리 경로가
  없는 부분은 필요한 어댑터를 검증한 뒤 사용하며, 단순 DB 값 변경을 앱 저장과
  동등한 완료로 보고하지 않는다.
- 현재 앱은 별도표기·비율 예외를 제외한 원재료 비율의 합계가 100%일 때만 저장한다.
  사진의 합계가 99%처럼 맞지 않으면 임의 자동배분·잔여비율 추가·예외 처리로
  통과시키지 않는다. 수정안을 준비하고 사용자에게 정확한 배합비를 확인한다.
- 기존 상품·원재료행 ID, 매장, 원재료 참조와 표시 순서를 보존하고, 별도표기는
  비율 null로 저장한다. 수입산 1차 상품의 수입업소명 등 앱의 필수 검증도 적용한다.
- 기존 원재료 참조는 앱처럼 유지하되 사진과 다른 제품·버전으로 바뀌는 경우
  해당 버전의 원재료 연결을 확인한다. 공통 마스터를 수정하면 영향 상품 전체를
  확인하며 다른 상품의 성분을 임의로 바꾸지 않는다.
- 2026-10-07 사용자 정정: 원재료 성분의 수정 원본은 원재료 마스터다.
  상품 줄의 composition/origin/name만 바꾸고 기존 원재료ID를 연결해 두는 방식은 금지한다.
  앱 ProductDao.getProductWithIngredients는 유효한 참조 마스터가 있으면 그 원재료의
  이름·성분·원산지를 우선 읽는다. 상품 줄은 배합비·순서·별도표기와 참조를 관리하며,
  성분 확인은 반드시 원재료 원본과 앱의 실제 조인 결과로 한다.
  원재료 입력 오류 정정은 해당 원재료에서 수행하고 연결 상품 전체를 확인한다.
  실제 다른 제품·버전이면 별도 원재료로 등록한 뒤 상품 참조를 변경한다.
  상품 줄의 중복 성분값을 맞추는 작업은 원재료 원본에서 파생한 동기화로만 수행한다.
- 저장 전 최신 원본·백업·기대값을 확인하고, 저장 후 상품·구성·마스터 참조·수정시각을
  재조회한다. 사진에 없는 가격·마트코드·가려진 값은 임의 변경하지 않는다.
- 대표품질은 현재 앱에서 상품과 연결 재료로 생성된다. 과거 product_quality 저장행이나
  print_records 출력 이력을 현재 값으로 덮어쓰지 않는다. 새 출력 필요 여부는 별도로 기록한다.
- 저울 연결과 자동 적용 설정을 확인하고 앱의 공통 작업함/CASPi 검증 경로를 따른다.
  연결 없는 상품에 PLU를 임의 지정하지 않는다. 앱 저장·저울 적용·실제 재출력을 구분한다.
- 사용자가 앱에서 동기화해 확인하도록 서버 반영 증거와 확인할 값을 안내한다.
  휴대폰 동기화 실행·화면 확인 전에는 휴대폰 반영 완료라고 보고하지 않는다.

점검을 시작하려면 다음 자료가 필요하다.

- 대상 매장
- 현재 시코드 운영상품과 상품별 대표품질
- CL-5200 저울의 최신 PLU 조회값 또는 실제 상품라벨
- 실제 사용 중인 모든 원재료의 한글표기사항 사진(이하 `원라벨`)
- 기한과 보관상태를 확인할 수 있는 현재 재고 또는 로트 정보

원라벨 사진은 전체 표시사항이 잘리지 않고 글자를 읽을 수 있어야 한다. 한 장으로 확인하기 어려우면 전체 사진과 항목별 확대 사진을 함께 받는다. 읽을 수 없는 내용은 추정하지 않고 `사진 판독 불가` 또는 `추가 사진 필요`로 판정한다.

## 전체 점검 순서

```text
대상 매장 확인
→ 시코드 운영상품 확인
→ 상품과 저울 PLU 대조
→ 실제 상품라벨 확인
→ 상품별 대표품질 확인
→ 대표품질 원재료 목록 작성
→ 중복 원재료 통합
→ 원재료별 원라벨 대조
→ 로트별 기한·보관상태 확인
→ 불일치·수정 필요사항 보고
```

앞 단계에서 확인되지 않은 항목을 임의로 통과시키지 않는다. 확인 가능한 다른 항목은 계속 점검하되, 최종 결과에는 미확인 사유를 남긴다.

## 1단계: 시코드 상품과 저울 PLU 점검

매장의 현재 운영상품은 시코드 앱 `products_{store}`를 기준으로 확인한다. 생산·판매 대상은 원칙적으로 `is_active = true`이면서 `is_operating = true`인 상품이다.

상품과 저울 PLU는 다음 우선순위로 대조한다.

1. 매장
2. 시코드 `mart_code` 또는 저울 상품코드
3. PLU 번호와 저장된 연결정보
4. 상품명은 보조 확인에만 사용

확인 항목은 다음과 같다.

- 시코드 상품이 올바른 저울 PLU와 연결되어 있는가
- 상품코드, 상품명과 정상가격이 일치하는가
- 현재 운영하지 않는 상품이 저울에 남아 있지 않은가
- 시코드에만 있거나 저울에만 있는 상품이 있는가
- 실제 출력한 상품라벨이 선택한 상품의 내용으로 정상 출력되는가

할인, 해동중, 전처리, 숙성중, 코드확인, 테스트 등 작업용 PLU는 이름만으로 제외하지 않는다. 앱의 운영상태와 실제 용도를 확인해 관리 제외 여부를 판정한다.

점검 상태는 `정상 연결`, `시코드에만 있음`, `저울에만 있음`, `잘못된 PLU`, `정보 불일치`, `관리 제외`, `확인 불가`로 기록한다.

## 2단계: 대표품질과 출력본 점검

상품과 대표품질을 별도 연결하는 절차는 없다. 시코드에 상품이 올바르게 등록되어 있으면 해당 상품의 대표품질이 정상적으로 표시되어야 한다.

- 선택한 상품의 대표품질이 정상적으로 표시되는지 확인한다.
- 대표품질이 없거나 다른 상품의 내용이 나오면 `상품 등록 확인 필요`로 보고한다.
- 대표품질 최종 수정일과 현장 비치본 출력일을 비교한다.
- 출력일은 대표품질 최종 수정일과 같거나 이후여야 한다.
- 출력일이 최종 수정일보다 이전이면 `최신 대표품질표 재출력 필요`로 판정한다.

대표품질을 수정한 경우에는 저장과 앱 반영을 확인한 뒤 상품라벨을 다시 확인하고 대표품질표를 재출력해야 한다. 실제 수정은 별도 요청을 받은 뒤 수행한다.

### 수정시각과 출력시각 기록

대표품질에 영향을 주는 상품 또는 공통 원재료를 수정할 때는 다음 시각과 증거를 변경 건별로 기록한다.

- 수정 대상과 수정 전·후 값
- 수정 승인자와 승인 내용
- 서버에 반영된 최종 수정시각
- 영향을 받는 전체 상품
- 상품별 대표품질 출력시각과 출력기록 ID
- 출력본 또는 실제 출력 내용의 확인 결과
- `출력시각 >= 해당 상품에 영향을 준 가장 늦은 수정시각` 비교 결과

공통 원재료를 한 번 수정해 여러 상품에 반영한 경우에도 출력 검증은 상품별로 각각 기록한다. 수정 후 출력기록이 없으면 `재출력 대기`, 출력시각이 수정시각보다 빠르면 `구 출력본·재출력 필요`, 이후이고 내용까지 일치하면 `최신 출력 확인`으로 판정한다. 출력기록이 앱 로컬에만 있고 서버 동기화되지 않은 경우에는 완료로 단정하지 않고 동기화 또는 현장 출력본을 추가 확인한다.

### `1차` 수입산 상품의 수입업소명

상품 태그에 `1차`가 있고 상품 원산지가 수입산이면 다음 세 곳의 수입업소명을 확인한다.

1. 시코드 상품의 비고
2. 저울 라벨의 `상품명5`
3. 실제 원재료 원라벨

- 시코드 상품 비고에 수입업소명이 있어야 한다.
- 비고의 수입업소명이 저울 라벨 `상품명5`에 들어가야 한다.
- 비고, `상품명5`와 원라벨의 수입업소명이 모두 같아야 한다.
- 비고 또는 `상품명5`가 비어 있으면 원라벨을 받기 전에도 `수입업소명 입력 필요`로 보고한다.
- 국내산 `1차` 상품에는 이 조건을 적용하지 않는다.

## 3단계: 원재료 목록과 중복 처리

상품별 대표품질에 표시된 모든 원재료를 추출한 뒤, 원재료 중심의 공통 점검 목록을 만든다. 같은 원재료가 여러 상품에 사용되면 원라벨 표시 적합성은 한 번 점검하고 그 결과를 사용하는 모든 상품에 연결한다.

원재료명이 같다는 이유만으로 자동 통합하지 않는다. 다음 정보가 같은 경우에만 동일한 원라벨로 묶는다.

- 제조사와 정확한 제품명
- 수입업소명(수입 원재료인 경우)
- 원산지
- 성분, 함량과 알레르기 표시
- 규격 또는 포장단위
- 원라벨 표시 버전

성분이나 알레르기가 다르면 별도 원재료로 분리한다. 공급업체만 다른 경우에도 실제 원라벨 표시가 같은지 확인한 뒤 공통 결과를 적용한다.

공통 원재료마다 그 원재료를 사용하는 전체 상품 목록을 저장한다. 원라벨 하나의 불일치가 여러 상품에 영향을 주면 영향 상품을 모두 보고한다.

## 4단계: 원라벨 필수 확인 항목

각 원재료의 실제 원라벨에서 다음 항목을 확인한다.

| 항목 | 확인 기준 |
| --- | --- |
| 원재료명 | 대표품질의 원재료와 실제 사용하는 제품이 같은지 확인 |
| 수입업소명 | 수입 원재료의 수입업소명을 확인하고, 다른 수입업소 제품이면 별도 원라벨로 구분 |
| 원산지 | 대표품질 및 상품라벨의 원산지와 일치하는지 확인 |
| 포장일 | 포장일 표시 제품은 실제 포장일을 확인 |
| 소비·유통기한 | 표시된 날짜와 현재 사용 가능 여부를 확인 |
| 보관기간 | `포장일로부터 n개월` 등 표시를 확인하고 필요한 경우 사용 가능 기한 계산 |
| 보관방법 | 냉장·냉동·실온 및 개봉 후 조건과 실제 보관상태를 비교 |
| 성분·함량 | 대표품질 및 상품라벨의 성분명, 함량과 복합원재료 구성의 누락·차이를 확인 |
| 알레르기 | 원라벨의 알레르기 유발물질이 대표품질과 상품라벨에 빠짐없이 반영됐는지 확인 |

대표품질에 있는 모든 원재료에 원라벨이 있어야 한다. 일부 원재료만 확인한 상품은 완료 처리하지 않는다.

고추·대파·무·양배추·콩나물 등 신선 야채는 원라벨에 소비·유통기한이 없는 것을
누락으로 판정하지 않는다. 신선 야채는 원산지와 품목을 대조하고, 현재 재고의 신선도와
실제 보관상태를 현장에서 확인한다. 별도의 포장일·소비기한 또는 보관방법이 표시된
제품은 그 표시가 있는 경우에 한해 함께 기록한다.

### 개별 포장 소스의 `별도표기` 처리

완제품 안에 개별 포장 소스를 넣어 판매하는 경우에는 소스 원라벨의 표시 면이 소비자에게 보이는지 확인한다.

- 소스 뒷면의 원재료명, 알레르기, 소비기한 등 한글표시사항이 완제품 포장 밖에서 가림 없이 보이면 대표품질과 상품라벨에 `별도표기`로 표시할 수 있다.
- `별도표기` 판정은 소스 원라벨이 실제 완제품에 함께 들어 있고, 표시 면 전체를 개봉하지 않고 읽을 수 있을 때만 인정한다.
- 소스 표시 면이 다른 원재료, 트레이, 스티커 또는 포장지에 가려져 읽을 수 없으면 대표품질과 상품라벨에 해당 소스의 필요한 표시사항을 직접 반영해야 한다.
- 같은 상품이라도 포장할 때마다 소스 방향이 달라질 수 있으므로, 현장 점검에서는 실제 진열 완제품에서 뒷면 노출 상태를 확인한다.
- 소비기한이 `별도표기`인 소스는 원라벨 표시 면이 보여도 실제 날짜가 인쇄된 위치와 날짜의 유효성을 별도로 확인한다.

### 공급 제품이 자주 바뀌는 원재료의 버전 관리

버터, 소스 등 같은 용도로 사용하지만 제조사·제품명·배합·원산지 또는 알레르기 표시가 자주 바뀌는 원재료는 기존 표시정보를 덮어쓰지 않고 원라벨 버전별로 관리한다.

- 현장 통칭이 같아도 정확한 제품명, 제조사, 성분·함량, 원산지 또는 알레르기가 다르면 서로 다른 원라벨 버전으로 등록한다.
- 상품의 대표품질에는 현재 입고되어 실제 생산에 사용하는 버전을 연결한다.
- 저울의 대표품질 3줄에는 비율 상위 3개 원재료가 모두 남아야 한다. 복합원재료의 내부 원산지 상세가 공간을 차지해 다음 순위 원재료가 빠질 때는 내부 후속 상세를 생략하고 다음 원재료를 우선 표시한다.
- 상품명2·3·4는 원재료별 고정 칸이 아니라 연속된 표시 공간으로 사용한다. 다음 원재료명이나 복합원재료의 여는 중괄호가 현재 줄의 남는 폭에 들어가면 같은 줄부터 이어 쓰고 상세 내용만 다음 줄로 넘긴다.
- 예: 가리비·버터·레몬주스 구성은 버터의 핵심 상세 원산지를 유지하면서 레몬주스의 제품명과 원산지도 표시한다.
- 버터처럼 일반 성분 뒤에 내부 복합원재료가 이어지는 표시는 선택한 상세 범위를 중괄호 `{...}`로 묶는다. 저울 여러 줄에 걸치면 앞줄에서 열고 다음 줄의 해당 원재료 마지막 상세에서 닫는다.
- 공급 제품이 바뀌면 새 원라벨을 확인한 뒤 현재 버전 연결을 변경하고, 이전 버전과 과거 점검기록은 보존한다.
- 동일 날짜에 두 버전을 함께 사용하면 두 버전을 모두 현재 사용으로 기록하고 각각 원라벨과 로트 기한을 확인한다.
- 다른 매장에 같은 원라벨 버전이 등록되어 있으면 성분 입력의 참고자료로 사용할 수 있지만, 현재 매장의 실제 박스와 제품명·제조사·표시 버전이 일치해야 적용한다.
- 제품 교체 여부는 원재료 통칭만으로 판단하지 않는다. 실제 원라벨 사진과 현재 재고 로트를 기준으로 선택한다.

## 5단계: 공통 표시와 로트별 기한 구분

한 원재료를 여러 상품에서 사용하더라도 점검 단위는 두 가지로 나눈다.

- `원라벨 표시 적합성`: 동일한 제품·표시 버전이면 한 번 검사하고 여러 상품에 공통 적용한다.
- `현재 재고 적합성`: 포장일, 소비·유통기한과 실제 보관상태는 박스 또는 입고 로트별로 각각 검사한다.

원라벨 내용이 적합해도 같은 원재료의 여러 박스나 로트에 기한이 다르면 각 기한을 별도로 확인한다. 표시가 같은 과거 사진만으로 현재 재고의 기한과 보관상태를 적합 처리하지 않는다.

## 6단계: 3자 대조와 판정

다음 세 자료의 원산지, 성분·함량과 알레르기 정보를 대조한다.

1. 시코드에서 확인한 대표품질
2. 실제 출력되는 상품라벨
3. 실제 사용 원재료의 원라벨

항목별 판정값은 다음과 같다.

- `일치`: 세 자료와 현재 상태가 확인 기준을 충족함
- `불일치`: 확인값이 서로 다름
- `표시 누락`: 필요한 항목이 한 자료에 없음
- `원라벨 없음`: 대표품질의 원재료에 대응하는 원라벨이 없음
- `기한 문제`: 기한 경과, 계산 불가 또는 별도 확인이 필요함
- `보관 부적합`: 원라벨 보관조건과 실제 보관상태가 다름
- `사진 판독 불가`: 사진에서 해당 내용을 읽을 수 없음
- `추가 확인 필요`: 자료만으로 동일 제품이나 적합 여부를 확정할 수 없음

확인되지 않은 항목은 `일치`로 간주하지 않는다.

## 7단계: 결과 보고

최종 보고의 중심은 정상 항목의 반복 나열이 아니라 불일치, 누락, 확인 불가와 수정 필요사항이다. 정상 항목은 상품 수, 원재료 수와 적합 건수로 요약할 수 있다.

### 불일치·수정 필요사항 표

| 상품 | 원재료 | 점검 항목 | 대표품질·상품라벨 | 원라벨·현장값 | 판정 | 수정 또는 확인 필요사항 | 영향 상품 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 예시 상품 | 예시 소스 | 알레르기 | 미표시 | 대두 함유 | 표시 누락 | 대표품질과 상품라벨 반영 필요 | 예시 상품 외 2개 |

보고서에는 다음 항목을 빠뜨리지 않는다.

- 시코드 상품과 저울 PLU의 불일치
- 대표품질이 없거나 잘못 표시되는 상품
- 대표품질 수정일보다 오래된 출력본
- `1차` 수입산 상품의 비고·상품명5·원라벨 수입업소명 누락 또는 불일치
- 원라벨이 없는 원재료
- 대표품질·상품라벨·원라벨의 원산지, 성분과 알레르기 불일치
- 수입업소명이 다른 원재료
- 기한 경과·확인 불가 및 보관방법 불일치
- 판독 불가 사진과 추가로 필요한 촬영 범위
- 공통 원재료 문제의 전체 영향 상품

## 점검 완료 조건

상품 하나는 다음 조건을 모두 확인해야 `적합`으로 완료할 수 있다.

- 시코드 상품과 저울 PLU가 정상임
- 실제 상품라벨이 정상 출력됨
- 대표품질이 정상 표시됨
- `1차` 수입산 상품은 비고·상품명5·원라벨의 수입업소명이 일치함
- 대표품질표 출력일이 최종 수정일과 같거나 이후임
- 각 수정 건의 수정시각, 상품별 출력시각, 출력기록 ID와 실제 내용 확인 결과가 기록됨
- 대표품질의 모든 원재료에 판독 가능한 원라벨이 있음
- 대표품질, 상품라벨과 원라벨의 원산지·성분·알레르기가 일치함
- 모든 현재 재고 로트의 기한과 보관상태가 확인됨
- 남은 불일치, 누락 또는 확인 불가 항목이 없음

점포 전체 결과는 `검사 수행 완료`와 `준법 적합 완료`를 구분한다.

- `검사 수행 완료`: 현재 운영상품을 모두 검사했고, 남은 문제를 불일치·수정 필요사항 보고서에 빠짐없이 기록한 상태
- `준법 적합 완료`: 현재 운영상품이 모두 `적합`이고 남은 불일치, 누락 또는 확인 불가 항목이 없는 상태

미확인 상품이나 원재료가 있으면 검사 수행을 완료한 것으로 처리하지 않고 그 수와 사유를 명시한다.
