# 공통 매출 지침

모든 매장의 매출 조회, 원본 보존, 검증과 보고에 공통으로 적용한다.

## 기준 원칙

- 매출 질문은 매장에 맞는 공급업체별 지침을 먼저 확인한다.
- Google Drive 파일은 매출 원본이며 임의로 내용을 수정하지 않는다.
- 검증된 Supabase 데이터를 공용 조회 기준으로 사용한다.
- 원본 파일 ID와 링크를 보존해 결과를 추적할 수 있게 한다.
- 같은 날짜 자료를 재처리할 때는 중복 행을 누적하지 않고 해당 날짜를 안전하게 교체한다.
- 동기화 후 저장된 행 수와 합계를 다시 읽어 검증한다.

## 계산 원칙

- 사용자가 수수료 차감 후 금액에서 차감 전 금액을 요청하면 적용된 수수료율을 확인한다.
- 20% 차감 후 금액의 차감 전 금액은 `차감 후 금액 ÷ 0.8`로 계산한다.
- 총매출, 행사팀 매출, 워터비 매출을 혼용하지 않고 어떤 금액인지 명시한다.
- 추정값이나 OCR 검토 대기 자료는 확정 매출과 구분한다.

## 보고 형식

텔레그램에 붙여 넣을 가능성이 있는 답변은 넓은 Markdown 표 대신 모바일에서 읽기 쉬운 짧은 텍스트 블록을 사용한다.

```text
2026년 8월 매출

[합계]
왕십리점 00,000,000원

[구분]
총매출 00,000,000원
행사팀 매출 0,000,000원
워터비 매출 00,000,000원
```
