# 양쪽에서 가능한 운영 작업

2026-10-07 사용자 합의. 씽크패드 이전은 상시 통신·자동 수집의 실행 주체를
옮긴 것이며, 업무를 Windows 전용/씽크패드 전용으로 나누라는 뜻이 아니다.

- **씽크패드:** 카스파이 통신, 요청 전달, 누계 수집, 결과 게시,
  상시 감시·알림 등 계속 실행되어야 하는 중앙 워커.
- **양쪽 모두 가능:** 개발, 점검, 매출 동기화, OCR·검산 등 요청형 작업은
  현재 컴퓨터와 씽크패드 모두 수행할 수 있다. 업무 종류로 호스트를 강제하지 않고
  준비된 환경·성능·접속 상태를 보고 편리한 실행 장소를 선택한다.
- **매출 자동 동기화:** 상시 자동 실행으로 운영할 경우 그 자동 실행은 씽크패드에 둔다.
  수동 동기화는 양쪽 모두 가능하다. 현재 상시 실행 장소는 다른 업무의 장소 제한이 아니다.

## 공통 기준

1. 어느 워터비 채팅에서도 작업을 맡는다. 현재 채팅에서 직접 또는 원격 실행해
   결과를 보고하며, 실행 장소가 다르다는 이유로 사용자를 다른 채팅으로 이동시키지 않는다.
2. 상시 워커와 요청형 작업을 구별한다. Windows 예약 작업 재활성화나 중앙 이중 실행은 하지 않는다.
3. 작업 장소와 운영 원본은 별개다. Windows 정지본 DB는 최신 원본으로 쓰지 않는다.
   로컬 OCR·검산은 새 작업 자료로 수행하고 원본 파일 ID·날짜·버전·검증상태를 보존한다.
4. 최종 결과는 기존 담당 적재 절차를 통해 같은 운영 원본에 반영하고 재조회로 검증한다.
   현재 호스트에 필요한 인증/환경이 없으면 원격 입구를 사용하거나 준비 부족을 명시한다.
   다른 호스트의 인증을 임의 복사하지 않는다.
5. 같은 출처·날짜의 작업이 진행 중인지 확인하고 중복 적재를 피한다.
   다른 세션 작업을 임의 중단하거나 새 작업으로 덮지 않는다.
6. 조회 요청은 동기화·삭제·복구 승인이 아니다. 동기화의 범위와 원본 정리는
   매출 담당 지침을 따른다. 앱 배포는 사용자 요청 때만 한다.

이 기준은 지침 해석의 정리이며, 실행 중인 워커·작업의 이전/재시작을 수행한 것이 아니다.
